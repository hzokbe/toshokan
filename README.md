# 📚 toshokan

Toshokan é uma **API REST** construída com **NestJS** que fornece operações completas de CRUD para gerenciamento de livros.

---

## 🚀 Como subir a API?

Use:

```bash
git clone https://github.com/hzokbe/toshokan

cd toshokan

cp ./.env.example ./.env

docker compose up -d
```

> 💡 Notas:
>
> - Você pode customizar o `.env` criado na raiz do projeto
> - Por padrão, a API estará disponível em `http://localhost:3000`

---

## 🛠️ Tecnologias

- **TypeScript**
- **NestJS**
- **Drizzle ORM**
- **PostgreSQL**
- **Docker**
- **Redis**

---

## 🎯 Objetivo

Praticar a criação de uma **API REST** utilizando **NestJS**, incluindo estruturação de projeto, persistência de dados e organização em camadas.
